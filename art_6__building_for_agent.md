# Building for agents and humans

- agennts should have thier own machine (computer sandbox)
- a clear contract with the human
- self improving mechanism (evry job has a target metric the should improve like AK autoresearch)
- They have their own identity but are supervised by the human
- Well documentented code interfaces


## what humans care about

- zero hassle set up
- having understandin of what is going on (tracing + grounding)
- right interface for the right task(dynamic interfaces)
- right interface for input
  - long term planning
  - jobs that need to be done

- right interface for output
  - overall health
  - job specific tracing and grounding
  - taks need to be unblocked
